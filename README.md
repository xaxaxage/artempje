# artempje — своя игра с друзьями

Бесплатный конструктор «Своей игры» (Jeopardy) в браузере: собираешь доску с вопросами, картинками, аудио и видео, выводишь на телевизор, а друзья жмут кнопку на своих телефонах.

## Возможности

- Редактор доски: темы, вопросы, ответы, стоимость, несколько раундов и финал.
- Картинки, аудио, видео и YouTube в вопросах и ответах: перетащить файл, вставить скриншот через Ctrl+V или дать ссылку.
- Два режима: «Простой» (ведущий сам отмечает ответы) и «С кнопками» (игроки заходят по коду или QR и жмут на телефоне).
- Честные кнопки: учитывается время реакции на телефоне, а не скорость интернета.
- Вопросы-ставки, финал со ставками и письменными ответами с телефонов.
- Пульт ведущего на телефоне: видно правильный ответ, можно управлять игрой.
- Отмена последнего действия, ручная правка очков, продолжение игры после перезагрузки страницы.
- Экспорт и импорт доски в файл (вместе с картинками).
- Команды (или «каждый сам за себя»), три раскладки экрана и пять тем — выбираются под ⚙ на каждом устройстве.
- Тест-стенд (`test/`): ведущий и несколько игроков на одной странице, чтобы проверить игру одному.

## Как это устроено

Сайт полностью статический, никакого своего сервера нет:

- доски и картинки хранятся в IndexedDB браузера ведущего;
- телефоны соединяются с компьютером ведущего напрямую через WebRTC ([PeerJS](https://peerjs.com/)); публичный сервер PeerJS нужен только для «рукопожатия».

Поэтому сайт можно бесплатно разместить на GitHub Pages или любом другом статическом хостинге.

## Запуск локально

Нужен любой статический сервер (модули ES не работают через `file://`), например:

```bash
npx serve .
```

## Публикация

Перед каждым `git push` запусти:

```bash
node tools/bump-version.mjs
```

Скрипт проставляет всем скриптам и стилям `?v=<версия>`. GitHub Pages разрешает браузерам кешировать файлы на 10 минут, и без этого игроки после обновления могли бы получить старый код. Ведущий и телефоны сверяют версии: устаревший телефон перезагружается сам, а ведущему показывается «Сайт обновился — обнови страницу».
